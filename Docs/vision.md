# Pourquoi les Pioupiounades ?

Beaucoup d'initiatives locales existent mais restent invisibles.

Les habitants veulent agir mais ne savent pas où chercher.

Les associations cherchent des bénévoles.

Les commerçants organisent des événements.

Pioupiounades rassemble ces initiatives pour faciliter la vie du quartier.

Permettre a chacun d'agir pour sa communaute

# Mission

Découvrir : quelles sont les actions qui existent dans mon quartier ?

Rejoindre : je peux donner de mon temps, savoir faire et energie

Agir ensemble : ensemble on va plus loin

# Valeurs

Proximité : je peux participer aux actions a pied

Simplicité : il me suffit d'un clic pour participer

Bienveillance : des actions pour embellir, reparer et partager

Impact local : nous sommes tous voisins

# Objectif

Faciliter les initiatives citoyennes de proximité.
