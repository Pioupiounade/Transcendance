# Backlog

## Epic 1 - Comptes utilisateurs

Les utilisateurs ont chacun un profil pour se decrire, gerer leurs preferences
et evoluer sur la plateforme. 

 - Feature : Creer un compte
 - Feature : Se connecter
 - Feature : Se deconnecter
 - Feature : Creer son profil (Utilisateur / Association / Commerce)
 - Feature : Modifier son profil
 - Feature : Supprimer son compte
 - Feature : Consulter un profil
 - Feature : Partager son profil (V2)
 - Feature : Gerer des amities (demande de connexion, accepter/refuse, enlever un ami)


## Epic 2 - Actions citoyennes

Les actions sont les evenements auxquels les utilisateurs peuvent s'inscrire. 
Les actions sont decrites avec des commentaires, une localisation, des horaires, des 
informations necessaires a l'execution. Elles peuvent etre crees par tous les utilisateurs, particuliers ou associations/commerces.

 - Feature : Signaler une action possible
 - Feature : Creer une action
 - Feature : Modifier une action
 - Feature : Supprimer une action
 - Feature : Partager une action (V2)
 - Feature : Decouvrir des actions
 - Feature : Consulter une action

## Epic 3 - Participation

Les utilisateurs s'inscrivent directement aux activites qui les interesse. La gestion des participations est directement faite par l'application. 

- Feature : S'inscrire a une action
- Feature : Se desinscrire d'une action
- Feature : Voir la liste des participants
- Feature : Voir les places restantes

## Epic 4 - Communication

Les createurs des activites peuvent envoyer des informations et communiquer avec/entre les participants.

- Feature : Envoi de message a un utilisateur
- Feature : Envoi de message a un groupe d'utilisateurs (ex: participants inscrits)
- Feature : Commentaire sur la page de l'action
- Feature : Commentaire sur le profil d'une organisation

## Epic 5 - Photos

Il est possible de charger des photos sur la plateforme pour illuster des suggestions d'actions, montrer l'avant/apres, illuster son profil.

- Feature : Gerer une photo sur son profil
- Feature : Gerer les photos sur une action possible
- Feature : Gerer les photos sur une action avant
- Feature : Gerer les photos sur une action apres

## Epic 6 - Notifications

Les utilisateurs peuvent parametrer les notifications qu'ils souhaitent recevoir en fonction des activites/suggestions nouvellement crees autour de chez eux. Ils recoivent egalement des notification si des mises jour, commentaires, messages sont envoyes.

- Feature : Gerer les preferences de notifications
- Les types de notifications :
    - Nouveau message
    - Nouveau commentaire
    - Nouvelle activite
    - Mise a jour d'une activite a laquelle on est inscrit (ex: modification, nouvel inscrit)

## Epic 7 - Carte

La carte permet de visualiser les activites suggerees, crees dans le quartier. A partir de la carte, je peux consulter le detail d'une activite ou en creer une.

- Feature : Afficher les actions
- Feature : Afficher les suggestions
- Feature : Consulter un point
- Feature : Creer une action / suggestion depuis la carte
- Feature : Localiser une action / suggestion

## Epic 8 - Administration

La panneau d'administration permet de piloter le bon fonctionnement de la plateforme.

- Feature : Voir la liste des utilisateurs
- Feature : Emvoyer un message aux utilisateurs
- Feature : Bloquer un compte
- Feature : Debloquer un compte
- Feature : Consulter, masquer une activite
- Feature : Consulter. marquer une suggestion
- Feature : Moderer les commentaires
- Feature : Moderer les photos
- Feature : Traiter les signalements envoyes pas les utilisateurs
- Feature : Gerer les categories d'action
- Feature : Attribuer/retirer un role administrateur/moderateur
